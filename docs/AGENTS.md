# docs

## Purpose

Project documentation, plans, issues, validation reports, and multi-session handoff.

## Ownership

- Owns: markdown and reports under `docs/`
- Parent owns: PRD / TASKS / CHANGELOG at repo root; root AGENTS.md rail

## Local Contracts

| Path | Role |
|---|---|
| `HANDOFF.md` | Canonical multi-session handoff |
| `plans/` | Implementation plans (file-first) |
| `issues/` | RCA / bug write-ups (file-first) |
| `validation/` | Mechanical + AC validation evidence |

- Do not put secrets in docs
- HANDOFF is required when a session ends mid-work

## Work Guidance

- Prefer updating HANDOFF over relying on chat memory
- Validation reports map commands to written AC (see kit evidence model)

## Verification

- Handoff readable alone after `/new`
- Validation artifacts record commands + exit codes when gates ran
