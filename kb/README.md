# Knowledge base (optional)

For projects grounded in external docs (APIs, platforms, regulations).

| File | Purpose |
|---|---|
| `SOURCES.md` | Canonical external URLs (official only) |
| `index.json` | Machine-readable file list + version |
| `*.md` | Topic notes — every claim cites SOURCES or Learn-style URLs |

## Rules
- Prefer primary docs over blogs.
- On conflict, official source wins.
- Do not invent API/connector/policy names.
